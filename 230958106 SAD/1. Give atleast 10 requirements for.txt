1. User Registration

Input: Name, Email, Phone, Address, Password, ID Proof
Output: Success message / Error message / Unique User ID
Processing:

  * Validate input fields
  * Check for duplicate accounts
  * Encrypt password
  * Store user info in database



2. User Login

Input: Email / Phone Number, Password
Output: Login success/failure message
Processing:

  * Validate credentials
  * Match credentials with database records
  * Initiate user session on success



3. Train Search

Input: Source Station, Destination Station, Travel Date
Output: List of available trains with timing, seat availability, and fare
Processing:

  * Query train database
  * Filter trains based on source, destination, and date
  * Check seat availability in each train



4. Seat Availability Check

Input: Train ID, Class (Sleeper/AC), Travel Date
Output: Number of available seats / Full
Processing:

  * Check bookings in reservation database for that train/class/date
  * Subtract booked seats from total seats



5. Ticket Booking

Input: Train ID, Class, Travel Date, Passenger Details (Name, Age, Gender), Payment Info
Output: Booking confirmation, PNR number, e-ticket
Processing:

  * Re-check seat availability
  * Assign seats and generate PNR
  * Deduct fare from user’s payment method
  * Update reservation database



6. Ticket Cancellation

Input: PNR number, User Authentication
Output: Cancellation success/failure, refund amount
Processing:

  * Validate PNR and ownership
  * Update seat status to available
  * Calculate refund based on cancellation policy
  * Process refund transaction



7. Payment Processing

Input: Card Number / UPI / Net Banking Details, Fare Amount
Output: Payment success/failure confirmation
Processing:

  * Validate payment details
  * Interface with payment gateway
  * Update transaction status



8. PNR Status Check

Input: PNR Number
Output: Current booking status (Confirmed / RAC / Waiting List), Passenger info
Processing:

  * Retrieve ticket info from reservation database using PNR
  * Display updated status based on changes in seat allocation



9. Admin - Add/Update Train Details

Input: Train Name, Number, Route, Timings, Coach Details, Fare
Output: Confirmation message / Error
Processing:

  * Validate input
  * Insert or update train information in database
  * Update route and fare mappings



10. Generate Reports (Admin)

Input: Date range, Train ID (optional), Report Type (e.g. Revenue, Passenger List)
Output: Downloadable report (PDF/Excel), Summary on screen
Processing:

  * Query bookings and payment tables
  * Aggregate data based on report type
  * Format and present the report




1. Flight Search and Availability Check

Input: Source, destination, travel date, number of passengers, class (economy/business).
Output: List of available flights with fare and time.
Processing:

  * Query flight schedule database.
  * Filter by availability and user preferences.
  * Return list sorted by departure time, price, or duration.



2. Passenger Booking

Input: Selected flight, passenger details (name, age, passport/ID), payment details.
Output: Booking confirmation, e-ticket, seat assignment.
Processing:

  * Validate input and payment.
  * Reserve selected seats.
  * Generate booking reference and e-ticket.
  * Update seat availability in database.



3. Payment Processing

Input: Card/bank details, amount, billing address.
Output: Payment receipt or error message.
Processing:

  * Securely process payment via payment gateway.
  * Handle success/failure cases.
  * Record transaction and link to booking.



4. Flight Cancellation

Input: Booking reference number, user authentication.
Output: Cancellation confirmation, refund (if applicable).
Processing:

  * Verify booking.
  * Check cancellation rules (refund eligibility).
  * Cancel ticket, release seat.
  * Initiate refund if within policy.



5. Seat Selection

Input: Booking reference, flight number, preferred seat.
Output: Updated boarding pass with seat number.
Processing:

  * Check seat availability.
  * Update passenger’s seat assignment.
  * Lock seat to prevent double booking.



6. Check-In and Boarding Pass Generation

Input: Booking reference or ticket number.
Output: Check-in confirmation and boarding pass (with gate, seat, and time).
Processing:

  * Validate timing (within check-in window).
  * Mark passenger as checked-in.
  * Generate QR/Barcoded boarding pass.



7. Frequent Flyer Program Management

Input: Member ID, flight details, points to redeem or accumulate.
Output: Points updated, redemption confirmation.
Processing:

  * Calculate miles/points based on flight.
  * Update loyalty account.
  * Deduct points if used for discounts.



8. Notification System (Email/SMS/App Alerts)

Input: User contact details, flight status.
Output: Alerts (booking confirmation, delay, gate change, etc.).
Processing:

  * Monitor flight and system updates.
  * Trigger and send notifications using templates.
  * Log sent messages.



9. Admin Panel for Flight Scheduling

Input: Flight number, origin, destination, aircraft ID, timings, frequency.
Output: New or updated flight record in the system.
Processing:

  * Validate data (no overlaps/conflicts).
  * Add/update flight schedule in DB.
  * Reflect changes in availability search.



10. Reporting and Analytics

Input: Date range, report type (sales, occupancy, delay stats).
Output: Downloadable charts, PDFs, summaries.
Processing:

  * Aggregate and analyze booking and operational data.
  * Generate charts, graphs, or tabular reports.
  * Export to user-specified format (PDF, Excel).
